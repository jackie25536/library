## 目前候選方案與公司測試

### 這個方案想改善什麼

目前採用的候選方案是：

**由已生效的 PWM 重建電壓，透過馬達電氣模型計算電流，再將模型電流或融合電流用於電流迴路回授。**

先聚焦一個問題：

> 馬達靜止、量測電流與模型電流已經接近時，改用模型回授，能否降低位置抖動？

兩條電流曲線接近，可能只是平均值與主要波形接近，小幅快速變動仍有差異。

如果電流量測雜訊使電流控制器持續調整輸出電壓，就可能造成實際電流、推力與位置波動。模型回授若能減少這部分雜訊對控制器的影響，就有機會降低位置抖動。

這能解釋目前觀察到的 ACS 現象，但**仍是候選設計，不代表已確認 ACS Servoboost Plus 的內部實作。**

### 電壓如何重建

針對目前使用的雙極性全橋（bipolar H-bridge），先採用理想平均電壓模型：

$$
\begin{aligned}
m[k-1] &= 2D[k-1]-1 \\
\hat u[k-1] &= m[k-1]\,V_{\mathrm{bus,model}}
\end{aligned}
$$

各訊號的意思是：

| 訊號 | 定義 |
|---|---|
| `D` | 對應作用區間內，線圈處於正母線電壓狀態的時間比例，範圍為 0～1 |
| `m` | 帶正負號的電壓輸出比例，範圍為 −1～1 |
| `Vbus_model` | 模型使用的母線電壓設定值，單位 V |
| `u_hat` | 重建的線圈平均電壓，單位 V |

因為全橋在正、負母線電壓之間切換，平均電壓為：

$$
D\,V_{\mathrm{bus,model}}
+(1-D)(-V_{\mathrm{bus,model}})
=(2D-1)V_{\mathrm{bus,model}}
$$

因此，`D = 50%` 對應平均電壓為零；這不表示線圈沒有瞬時 PWM 電壓或電流漣波。

實作時注意三件事：

- **使用已經生效的 PWM。**  
  `u_hat[k-1]` 對應前一段已經作用在馬達上的輸出，包含必要的限制與調變；不能直接使用尚未生效的新電壓命令。

- **確認韌體中的 duty 定義。**  
  上式的 `D` 不一定等於某一個 PWM 腳位或比較暫存器的數值。若韌體已經提供帶正負號的 `m`，就不再做一次 `2D-1`。

- **`Vbus_model` 可以先使用固定設定值。**  
  這與我們對 `SLVBUS` 角色的推測一致。實際母線 39 V、設定 29 V 的觀察，只表示該條件下調整模型電壓比例有助於波形對齊，不能直接套用到其他平台。

這個基本式尚未包含死區時間（dead time）、開關壓降等電壓誤差。固定電壓比例也不能完整取代這些修正。

### 電流模型如何更新

馬達電氣模型為：

$$
L\frac{di}{dt}=u-Ri-K_e v
$$

意思是：線圈電壓扣掉電阻壓降與反電動勢後，剩餘電壓決定電流變化率。

模型中的參數統一使用：

- `R`：Ω；`L`：H；`Ts`：s。
- `v`：m/s；`Ke`：V·s/m。
- 電流：A；電壓：V。

若模型每次在 20 kHz 中斷中更新，`Ts = 50 μs`。這不等於已確認 PWM 的實際更新時刻，兩者仍需核對。

**前向歐拉更新式**

$$
i_{\mathrm{pred}}[k]
=
\hat i[k-1]
+
\frac{T_s}{L}
\left(
\hat u[k-1]
-R\hat i[k-1]
-K_e v[k-1]
\right)
$$

其中：

- `i_pred[k]`：本拍由電氣模型預測的電流。
- `i_hat[k-1]`：上一拍保留下來的模型狀態。
- `u_hat[k-1]`：前一作用區間的重建電壓。

對應程式：

```c
// 全部使用 SI 單位；輸入須對應正確的作用區間。
i_pred = i_hat
       + (Ts / L) * (u_hat_prev - R * i_hat - Ke * v_prev);
```

靜止測試時，若速度與反電動勢相對影響很小，可先近似 `Ke * v = 0`。移動測試則需保留此項。

**精確離散更新式**

$$
\begin{aligned}
a &= e^{-RT_s/L} \\
b &= \frac{1-a}{R} \\
i_{\mathrm{pred}}[k]
&=
a\hat i[k-1]
+
b\left(\hat u[k-1]-K_e v[k-1]\right)
\end{aligned}
$$

對應程式：

```c
// 初始化或參數改變時，重新計算。
a = expf(-R * Ts / L);
b = (1.0f - a) / R;

// 每拍更新。
i_pred = a * i_hat + b * (u_hat_prev - Ke * v_prev);
```

每拍只需乘加運算，不必每拍計算 `exp()`。

這裡的「精確」，是指固定 `R`、`L`，且每個取樣區間內淨輸入電壓保持不變的模型；不是重建所有 PWM 開關漣波。

前向歐拉的純電氣模型穩定條件為：

$$
0<\frac{RT_s}{L}<2
$$

這只檢查模型本身，不能代替完整電流迴路的穩定性驗證。

### 是否加入量測修正

先保留一個可選的量測修正：

$$
\hat i[k]
=
i_{\mathrm{pred}}[k]
+
K_o\left(i_{\mathrm{meas}}[k]-i_{\mathrm{pred}}[k]\right)
$$

`i_meas` 是電流感測鏈提供的量測值；`K_o` 是無因次修正比例。

| `K_o` | 更新結果 |
|---|---|
| `0` | 完全使用電氣模型，不加入量測修正 |
| `0 < K_o < 1` | 以模型為基礎，加入部分量測修正 |
| `1` | 更新後的 `i_hat` 等於 `i_meas` |

較小的 `K_o` 通常減少量測雜訊直接進入估測值，但也更依賴電壓重建與馬達參數的準確度。增加 `K_o` 可以修正部分模型偏差，卻不保證消除所有穩態誤差。

目前先用 **`K_o = 0` 作為逆向候選的基準**；非零 `K_o` 保留為後續比較方案，不預設 ACS 一定使用融合。

實作前有一個必要條件：

> 量測值與模型預測必須對應相同時間，並納入量測濾波的影響。

SDFM 輸出具有濾波與延遲。不能只因為兩個變數在同一次中斷取得，就直接認定可以相減。這個時序介面需要先釐清，再啟用非零 `K_o`。

### 如何接入既有電流迴路

電流控制器使用的回授定義為 `i_fb`：

$$
e_i[k]=i_{\mathrm{ref}}[k]-i_{\mathrm{fb}}[k]
$$

先區分三種模式：

| 模式 | 電流 PI 使用的回授 | 模型設定 |
|---|---|---|
| 校準／原始回授 | `i_meas` | 模型持續運算，`K_o = 0` |
| 純模型回授 | `i_hat` | `K_o = 0` |
| 融合回授 | `i_hat` | `0 < K_o < 1`，時序確認後測試 |

校準期間先使用原始電流回授，避免量測修正把模型誤差掩蓋掉。確認模型後，再比較回授切換的效果。

每拍的執行順序是：

1. **取得前一作用區間的輸出資料。**  
   重建 `u_hat_prev`，確認與模型更新區間一致。

2. **更新模型。**  
   計算 `i_pred`；若使用融合，再做量測修正。

3. **依測試模式提供電流回授。**  
   既有 PI 根據 `i_ref - i_fb` 計算新輸出，再經過限幅、調變與硬體更新。

4. **保留狀態與輸出歷史。**  
   保留本拍 `i_hat`，並追蹤新 PWM 實際生效的時間。

模型可在啟動時以有效量測初始化一次，之後持續遞迴；不要每拍都重新覆寫為量測電流，否則已經改變了候選演算法。

切換回授前，需處理回授跳變與 PI 狀態，避免突然造成電壓跳動。**硬體過流保護、量測電流監控、電流限制及抗積分飽和必須保留，不能只靠模型電流保護馬達。**

### 公司先驗證什麼

先在靜止條件下，完成最小比較：

1. 原始量測回授。
2. 純模型回授，`K_o = 0`。
3. 必要時，再比較小量量測修正。

固定位置、負載、控制器增益、量測頻寬與觀察時間，至少一起記錄：

| 觀察量 | 用途 |
|---|---|
| 位置回授的 RMS、峰對峰值 | 確認位置抖動是否改善 |
| `i_meas`、`i_pred`、`i_hat` | 分開觀察平均差異與快速波動 |
| `i_meas - i_pred` | 觀察修正前的模型偏差，需先確認量測時序 |
| 實際使用的 PWM／重建電壓 | 觀察控制器輸出波動是否改變 |

判讀時分清楚：

- **模型電流變平滑**：表示估測訊號的波動減少。
- **位置抖動降低**：才是目前要達成的控制效果。
- **實際電流是否更穩定**：若要進一步確認，需要具有足夠精度、頻寬且時間對齊的獨立電流量測。

模型曲線平滑，不能單獨證明實際電流更穩定。若出現異常電流、振盪、漂移、持續飽和或模型偏差擴大，依既有安全測試規範停止或退出測試模式。

### 目前的證據與未解問題

- **ACS 實測觀察**：靜止下 `iq` 與 `iq1` 已接近，啟用 ACS Servoboost Plus 後，位置抖動明顯降低。
- **目前工程推論**：電氣模型回授能解釋這種現象，仍需區分純模型與量測融合等可能作法。
- **Normal 既有測試**：已切換模型回授，但位置抖動沒有明顯改善。這是尚未解釋的差異，不能忽略。
- **本次方案定位**：核心架構延續既有方法；這次先把電壓定義、更新時序、回授位置與判讀方式固定下來，並未提出一個已驗證能改善 Normal 的新演算法。

下一步要確認的是：**同一組靜止條件下，回授切換究竟改變了哪些訊號，以及這些改變有沒有降低位置抖動。**
