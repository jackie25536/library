格式與計算說明

舊格式依序為 Axis、Target Radius、Start pos、End pos、Speed、Acceleration、Jerk、Move time、Settle time； 新格式會在 Acceleration 後加入 Dec，後續 Jerk、Move time、Settle time 順延一欄。CSV／TXT 可使用逗號或 Tab 分隔。

Dist = ABS(End pos − Start pos)；Total time = Move time + Settle time。 分組條件為 Competitor + Axis + Dist + Target Radius；Speed、Acceleration、Dec 與 Jerk 不影響可比較資格。 同一條件至少有兩個已啟用競品即可排名，缺少資料顯示 N/A；非 X／Y 的尾端 Gain、Period 等附加資訊列會自動略過。
