Bode 到底在觀察什麼？

先看機器怎麼回應，再把它畫成曲線。

先想一個實際問題

你讓平台慢慢往返，它可能跟得很好。改成快速往返，它的動作可能變小，也可能比命令晚一些。

Bode 想回答的就是：當我用不同的快慢去推動這個系統，它會跟著動多少？又會晚多少？

這裡的「快慢」是往返的頻率，不是速度數值有多大。每秒往返一次叫 1 Hz，每秒往返五次叫 5 Hz。測試時所施加的正弦輸入頻率，稱為激振頻率（excitation frequency）。

用專業術語來說，頻率響應（frequency response）描述系統在各頻率下，穩態正弦輸出相對於輸入的幅值比與相位差。Bode 圖把這兩項資訊分開呈現：上圖是幅頻特性（magnitude response），下圖是相頻特性（phase response）。「穩態」是指起始變化消退後，持續重複的反應。

像跟著別人的手一起移動

想像有人把手左右擺動，你試著跟著擺。對方慢慢擺，你比較容易跟上；對方越擺越快，你可能擺不到同樣的幅度，也可能晚一點才到達最左或最右。

我們可以分開問兩件事：一是「你擺得有多大」，二是「你晚了多少」。Bode 的上下兩張圖，正是把這兩件事分開記錄。

對照到專業用語：「擺得有多大」要換成輸出與輸入的振幅比；「晚了多少」要換成輸出相對於輸入的相位落後（phase lag）。例如波峰晚了八分之一個週期，就對應 45° 的相位落後。

這個比喻只幫助理解幅度與先後，沒有指定實際訊號是位置、速度或電流。不是所有機台都只會越快越小；有些機械在特定頻率反而會動得特別大，後面討論共振時再看。

一個頻率，如何得到上下兩個點？

先不要看整條曲線。只看 5 Hz 這一次測試。

第一步：求振幅比（amplitude ratio）。

先看輸出相對於輸入有多大。這裡比較的是波形從中間線到波峰的高度，也就是「振幅」，不是任意時刻的兩個數值相除。

輸入振幅是 10，輸出振幅約為 7.07。所以輸出約是輸入的 0.707 倍，也就是約 70.7%。這個例子的兩個訊號單位相同，因此單位在相除時約掉。

R=AyAu=7.07110≈0.7071R = \frac{A_y}{A_u} = \frac{7.071}{10} ≈ 0.7071
公式文字版

振幅比 R = 輸出振幅 / 輸入振幅 ≈ 7.071 / 10 ≈ 0.7071。

第二步：把振幅比換成分貝（decibel，dB）。

dB 用對數表示比例，不是另一份量測。此例的振幅比無因次，因此可直接使用下列換算式；下一章再拆解為什麼用對數。

M=20log10(R)≈-3.01dBM = 20\log_{10}(R) ≈ -3.01\ \mathrm{dB}
公式文字版

幅值 M = 20 × log10(振幅比) ≈ −3.01 dB。

於是在上方的幅值圖，橫軸找到 5 Hz，縱軸找到 −3.01 dB，就得到一個點。

第三步：由對應波峰的時間差求相位差（phase difference）。

把「晚到的時間」換成一個週期中的角度。5 Hz 代表一秒五個週期，所以週期（period）T 是 200 ms。輸出波峰晚了 Δt = 25 ms，等於晚了 25 / 200 = 1/8 個週期。

一個週期記成 360°，八分之一個週期就是 45°。我們以輸入為基準，把輸出晚到寫成負號，因此是 −45°。

φ=-360°ΔtT=-360°25200=-45°\phi = -360^{°}\frac{\mathrm{Δt}}{T} = -360^{°}\frac{25}{200} = -45^{°}
公式文字版

相位 φ = −360° × 波峰時間差 / 週期 = −360° × 25 / 200 = −45°。

於是在下方的相位圖，橫軸同樣找到 5 Hz，縱軸找到 −45°，再得到一個點。

這裡的「晚到」是此正弦頻率下的波形相位關係，不能直接當成系統固定的計算或通訊延遲。本例的波峰時間差會隨頻率改變，詳見附錄。

這兩個點是一組：它們描述的是同一個頻率、同一次輸入與輸出之間的關係。 上圖不是單獨的輸出振幅，下圖也不是平台的位置。

為什麼要換很多頻率？

只測 5 Hz，只知道系統在 5 Hz 的反應。就像只看一個人的走路，不能知道他跑步時能不能跟上。

我們依序換頻率，每次都記錄振幅比與相位，再把各頻率的點排列起來，才得到 Bode 曲線。這種逐頻施加正弦輸入的量測方式稱為步進正弦掃頻（stepped-sine sweep）。互動圖的整條曲線由模型計算，亮點只標示目前選取的頻率；不代表同時注入所有頻率。

在穩定的線性時不變系統（linear time-invariant system，LTI）中，等起始反應消退後，正弦輸入會得到同一頻率的正弦輸出，改變的是振幅與相位。「時不變」表示同樣的輸入測試不會只因開始時間不同，就得到不同的系統特性。這就是為什麼一個頻率能用幅值比與相位差描述；理論來源列於附錄。

實機有摩擦、飽和或雜訊時，輸出可能不再是乾淨的正弦波。此時不能直接拿歪掉的波峰做完整判斷；通常要擷取與輸入同頻的分量，並檢查量測品質。FFT、同步解調與 coherence 留到第六章逐步說明。

調機時，先問哪三個問題？

  1. 我比較哪兩個訊號？ 是電流對速度，還是速度命令對速度回授？先講清楚，才能知道曲線在說什麼。
  2. 在這個頻率，輸出是輸入的多少？ 注意是同頻分量的振幅比，並保留兩個訊號各自的單位。
  3. 輸出相對於輸入，領先還是落後多少？ 看相位，不只看幅值高低。

頻率響應的讀值不等於穩定性判斷。 不能只看到幅值跨過 0 dB，就直接說是共振或不穩定；必須先確認輸入、輸出與迴路結構。開迴路與 PM、GM 在第三、四章處理。

訊號、假設與計算式

輸入 u(t) 是速度命令，輸出 y(t) 是速度回授，單位皆為 mm/s；振幅為相對於零的峰值，不是峰對峰值，也不是 RMS。此例沒有平均速度偏置。

本頁選用低頻增益為 1、轉折頻率 f_c = 5 Hz 的一階低通模型，代表一個簡單的跟隨反應。這個模型是教學選擇，不是由你的機台辨識而得，也不是某組 AutoTune 參數的預測。

G(s)=11+s/(2πfc)G(s) = \frac{1}{1 + s/(2\pi f_c)}
公式文字版

G(s) = 1 / [1 + s / (2π × f_c)]，其中 f_c = 5 Hz。

在頻率 f 下，計算振幅比與相位，再產生穩態波形：

r = f / f_c
R = 1 / sqrt(1 + r*r)
φ = -atan(r)                  // 此處先用弧度計算
u(t) = 10 * sin(2π*f*t)
y(t) = 10 * R * sin(2π*f*t + φ)
幅值(dB) = 20 * log10(R)
相位(deg) = φ * 180 / π
T = 1 / f
波峰時間差 Δt = -φ / (2π*f)

這裡的 Δt 是在這個正弦頻率下，兩個對應波峰的時間差。它會隨頻率改變，不能把它直接當成控制器固定的計算或通訊延遲。

剛開始注入時，系統通常還包含隨時間消退的暫態響應（transient response）。本圖省略這段，只呈現穩態；實際掃頻仍需等待暫態充分消退，再擷取足夠長度的資料。

幅值、相位與座標怎麼讀

把刻度讀成比例，把相位讀成波形關係。

先把上下兩張圖讀對

第一章把一次正弦測試變成兩個點。這一章要練習的是：讀到一個座標時，能說出它對應什麼比例、什麼相位關係，而不只是記住曲線長相。

兩張圖共用頻率橫軸；上圖讀幅值，下圖讀相位。一般 Bode 圖的頻率軸是對數刻度（logarithmic scale），幅值以 dB 表示，相位以角度表示。相位縱軸仍是一般等距角度刻度，不是對數。

先沿用第一章「速度命令 → 速度回授」的同單位例子，最後再看「電流命令 → 速度回授」為什麼必須保留單位。

幅值：負 dB 不是負的速度

想像影印機把圖放大或縮小：放大兩倍、保持原大小、縮小一半，是不同的比例。dB 就像把這些「幾倍」換成另一種標籤，沒有重新量一次，也沒有改變原本的波形。

在這個同單位例子裡，輸出振幅除以輸入振幅，得到振幅比（amplitude ratio） R；幅值圖顯示的是 R 的對數表示：

M=20log10(R),R=10M/20M = 20\log_{10}(R),\qquad R = 10^{M/20}
公式文字版

幅值 M（dB）= 20 × log10(R)；反過來，振幅比 R = 10^(M / 20)。

為什麼是 20，不是 10？分貝原本用 10 × log10(功率比)；當功率與振幅平方成正比、而且比例常數相同時，平方移到對數前面，便得到 20 × log10(振幅比)。控制領域沿用這種幅值表示法；速度／電流的頻率響應不是功率比，不能直接把它的 −3 dB 說成馬達功率剩一半。

頻率：等距的是倍數，不是差值

一般直尺每格增加相同長度；對數頻率軸則像一把「倍數尺」。10 → 100 Hz 和 100 → 1000 Hz 都增加十倍，所以在圖上佔同樣寬度。

專業上，頻率相差十倍叫一個 decade（十倍頻程，簡寫 dec）；相差兩倍叫一個 octave（倍頻程）。因此 50 → 100 Hz 與 100 → 200 Hz 也是等距，雖然分別差了 50 Hz 與 100 Hz。

這讓低頻和高頻都能看得見。如果用 0～5000 Hz 的線性軸，10～100 Hz 只佔很小一段；換成 log 軸，這一個 decade 就能和 100～1000 Hz 一樣清楚。log 軸不能包含 0 Hz，因為零沒有有限的對數。

下面可切換「對數」與「線性」。兩種畫法使用完全相同的頻率與幅值資料，只改橫軸位置；系統不會因為換座標而改變。

斜率：−20 dB/dec 到底下降多少？

先把它讀成一句話：頻率乘上 10，幅值下降 20 dB，也就是振幅比變成原來的十分之一。 不是每增加 10 Hz 就下降 20 dB，也不是振幅每次減掉 20。

例如一段曲線在 10、100、1000 Hz 的振幅比分別是 1、0.1、0.01，幅值就是 0、−20、−40 dB。在對數橫軸上，這是一條等斜率直線。

若只把頻率加倍，同一條 −20 dB/dec 曲線會下降約 6.02 dB，振幅比減半。−40 dB/dec 則是在頻率變十倍時，振幅比變成百分之一。

這種「幅值每十倍頻率改變多少」稱為幅頻斜率。兩點間的平均斜率為：

S=M2-M1log10(f2/f1)dB/decS = \frac{M_2-M_1}{\log_{10}(f_2/f_1)}\quad \mathrm{dB/dec}
公式文字版

兩點間平均斜率 S = (M2 − M1) / log10(f2 / f1)，單位 dB/dec；頻率須為正，且 f2 不等於 f1。

相位：先看先後，再看角度怎麼寫

相位把「在一個週期中的位置」寫成角度。以輸入正弦波為基準，輸出波峰晚了四分之一週期，通常寫為 −90°，稱為相位落後（phase lag）；早了四分之一週期寫為 +90°，稱為相位領先（phase lead）。

不過正弦波每一圈都重複。像時鐘指針繞完一圈又回到同一方向，−181° 再加一圈 360°，就成了 +179°，指向仍然相同。

sin(ωt-181°)=sin(ωt+179°)\sin(\omega t-181^{°}) = \sin(\omega t+179^{°})
公式文字版

sin(ωt − 181°) = sin(ωt + 179°)；此式以角度表達相位，實際程式計算 sin 時要統一換成弧度。

  • 相位包覆（phase wrapping）把角度限制在選定的一圈內，例如 −180° ≤ φ < +180°。因此連續相位從 −179° → −180° → −181°，包覆顯示會變成 −179° → −180° → +179°。數字跳了，正弦波沒有跳。 +180° 與 −180° 也表示同一方向，只是軟體要選其中一端顯示。
  • 連續相位／相位展開（unwrapped phase）則把跨過邊界的角度接回連續分支，保留跨頻率變化的趨勢。在原本一路落後的曲線上看到包覆後的 +179°，不能直接說「機器突然從落後變領先」。要連同前後頻率與連續分支一起看。

單位：同一台機器，為什麼整條曲線會上下移？

想像同一段長度，寫成 1 m 或 1000 mm，物理長度沒變，但數字變了。頻率響應也一樣：改單位會改變幅值的數字，不是機器突然變強或變弱。

第一章的輸入、輸出都是 mm/s，所以振幅比無因次。若輸入換成電流，則受控體頻率響應是「速度／電流」，例如 (mm/s)/A，單位不能約掉。嚴格寫 dB 時，要把幅值除以一個同單位的基準 G_ref，才對無因次數取對數：

M=20log10(|G|Gref)M = 20\log_{10}\left(\frac{|G|}{G_{\mathrm{ref}}}\right)
公式文字版

幅值 M = 20 × log10(|G| / G_ref)；例如選 G_ref = 1 (mm/s)/A，0 dB 就對應這個基準。

因此 (mm/s)/A 圖上的 0 dB，不是「速度跟電流一樣大」，也不自動代表頻寬。它只表示幅值等於該圖採用的基準。

用一個虛構的 100 Hz 資料點練習：TXT 的幅值是 0.02 (mm/s)/count、相位 −100°，驅動器峰值電流 Ipeak = 20 A。這裡 count 專指電流命令刻度，不是編碼器計數。

  1. 1 count = 0.1% × 20 A = 0.02 A。
  2. 原本「每一個 count 的速度」改成「每一安培的速度」，要除以每刻度電流：0.02 / 0.02 = 1 (mm/s)/A。不是再乘上 0.02。
  3. 若速度也改成 m/s，則速度數字再除以 1000，得到 0.001 (m/s)/A。

每張圖分別以「1 個所顯示的頻率響應單位」作為 dB 基準時，以上三個數值對應 −33.98、0、−60 dB。數字不同，指的是同一個物理資料點。

④ 改單位，幅值移動多少？

虛構的 100 Hz 資料點

各表示法的 dB 都以 1 個該頻率響應單位為基準；物理資料點不變。

一般化地說：若輸出數字乘上 a、輸入數字乘上 b，新的頻率響應數字就乘上 a / b。正的固定倍率只讓整條幅值曲線上下平移，不改變相位、頻率位置或斜率。例如只把 mm/s 改成 m/s，幅值就平移 −60 dB。

這不表示可以隨意改倍率讓 AutoTune 通過。繪圖基準、慣量估算與控制器增益換算，必須使用同一份訊號與單位定義；否則圖看起來合理，算出的參數仍可能錯誤。力／轉矩與電流的換算，會在下一章連同 Plant 訊號路徑說明。

互動圖使用的定義

  • 振幅圖：輸入 u(t) = 10 sin(2πt)，輸出 y(t) = 10 R sin(2πt)，單位都是 mm/s。頻率固定 1 Hz，只改正的振幅比 R；沒有宣稱這是一台已辨識的機器。圖的速度縱軸隨最大振幅調整，數值仍以刻度為準。
  • 斜率圖：M(f) = S × log10(f / 10 Hz)，以 10 Hz、0 dB 為固定參考點；R(f) / R(10 Hz) = 10^(M(f) / 20)。只示範幅值形狀，不替這段曲線指定相位或穩定性。
  • 相位圖：輸入為 sin(2πt)，兩條輸出分別為 sin(2πt + φ) 與 sin(2πt + φ_wrapped)；幅值皆為 1，以正規化數值表示。程式先將角度乘上 π / 180 再計算正弦，不是把角度數字直接送進 sin。
  • 包覆區間採 [-180°, 180°)：先用正餘數把 φ + 180° 放進 [0°, 360°)，再減 180°。+180° 顯示為 −180°，兩端不重複。
  • 單位算例只含一個虛構資料點；電流為峰值安培基準。正倍率不改相位；若包含負號反轉，則另有 180° 的相位改變，不能套用「相位不變」這句話。

Hz 與 rad/s 要分開

f 是每秒幾個週期，單位 Hz；激振角頻率 ω = 2πf，單位 rad/s。它們描述同一個激振的快慢，只差倍率。兩者都用 log 軸時，頻率比與 dB/dec 斜率相同，但刻度數字不同。

不要和旋轉馬達的「速度回授 rad/s」混淆：一個是訊號隨時間往返的角頻率，另一個是轉軸的機械角速度。單位寫法相同，描述的量不同。

BODE LEARNING NOTES / 03

Plant、開迴路與閉迴路

先找出輸入與輸出，再問這條曲線代表什麼。

同一台平台，為什麼有三種 Bode？

想像你推著一台載貨的小車，希望它維持指定速度。車子變慢，你多推一點；車子太快，你少推一點。車子的重量與阻力沒有換，但「你怎麼修正」會改變最後的跟隨效果。

  • Plant（受控體）問的是：「我施加多少推力，車子會動出多少速度？」它描述被控制的對象。
  • 開迴路傳遞（loop transfer）問的是：「一個速度誤差，經過控制器與車子走一趟，會產生多少回來的速度變化？」它把控制器與受控體連在一起看。
  • 閉迴路傳遞（closed-loop transfer）問的是：「我指定一個速度，持續比較並修正後，車子實際跟上多少？」它看的是命令到輸出的結果。

三種曲線不是三台機器，而是同一套系統中，不同訊號之間的關係。 前兩章已經學會讀幅值與相位；現在先問清楚：這一次究竟拿誰除以誰？

先把四個訊號放回路徑

把「你」換成速度控制器，把「推車」換成線性馬達與平台。我們先只看速度迴路，位置迴路暫時放在外面。

訊號在做什麼本章單位
r：速度命令希望平台怎麼動mm/s
y：速度回授平台實際怎麼動；本例假設量測理想mm/s

e=r-ye = r-y
公式文字版

速度誤差 e = 速度命令 r − 速度回授 y。

Plant：你送進電流，平台回多少速度？

受控體傳遞函數（plant transfer function）記成 G。在本章的訊號定義下，它的輸入是電流命令 u，輸出是速度回授 y。

G=YUG = \frac{Y}{U}
公式文字版

G = 速度的複數響應 Y / 電流命令的複數響應 U；本章單位為 (mm/s)/A_peak。

這裡的大寫 U、Y 是同一激振頻率下的複數響應，同時保留振幅與相位，不是任意時刻拿兩個瞬間值相除。Bode 再把這個複數比值拆成幅值與相位兩張圖。

Plant 的邊界由輸入、輸出的位置決定。若輸入是「電流命令」而不是實際電流，命令到實際電流之間的電流迴路動態，也可能包含在量到的 Plant 裡；速度估測或回授濾波也同樣要看取樣位置。Plant 不一定只是一塊純機械。 本章互動先假設電流立即跟上命令、速度量測理想，完整條件放在附錄。

對照你實際會載入的 TXT，可以先這樣辨認：

輸入 → 輸出Plant 的原始單位
電流刻度 → 線性速度(mm/s)/count；count 指電流命令刻度
推力命令 → 線性速度(m/s)/N；依檔案實際速度單位
轉矩命令 → 旋轉速度(rad/s)/(N·m)

檔案單位不同，要先做第二章的倍率換算，不能把每條 Plant 都當成無因次。也不能只看到 Plant 高於 0 dB，就說速度放大超過命令、發生共振或不穩定。

開迴路：沿控制路徑走一趟

假設比較點出現一個小小的速度誤差：控制器 C 把它變成電流，Plant G 再把電流變成速度。先看這一趟產生多少速度回來，不要在同一趟的乘積裡再做一次「命令減回授」。

這個一圈的傳遞叫迴路傳遞函數（loop transfer function），本章記成 L。速度回授採相同單位、回授路徑倍率為 1，因此：

L=CGL = C G
公式文字版

L = 控制器 C × Plant G；本章採單位負回授，負號在比較點，沒有另外乘進 L。

  • C 的單位是 A_peak/(mm/s)，G 的單位是 (mm/s)/A_peak，相乘後單位約掉，所以 L 是無因次（dimensionless）。
  • |L| = 1，也就是開迴路 0 dB，表示這一趟回來的變化量和起始誤差一樣大；不是閉迴路輸出恰好跟上，也不是看到這個點就算共振。

「開迴路」在這裡是用來分析閉迴路的一圈傳遞，不表示你的機台量測時一定把所有控制都關掉。電流迴路可能仍然閉合；某些辨識方法也能在維持速度回授時取得 Plant。能否這樣量、取得的是哪一段，仍要確認注入位置、量測訊號與計算方式，不能只靠檔名判定。

閉迴路：持續比較後，命令跟上多少？

閉迴路表示輸出會回來影響控制器。平台變慢時，控制器看見誤差變大，便增加電流修正；但機械反應、量測與計算都可能帶來相位落後，因此「有回授」不代表一定跟得準或一定穩定。

先把這條因果路徑寫出來，就能知道閉迴路公式為什麼有分母。

第一步：控制器看到的不是完整命令，而是誤差。

e = r − y，控制器輸出 u = C e，Plant 輸出 y = G u。代在一起後：

Y=GC(R-Y)Y = G C(R-Y)
公式文字版

Y = G × C × (R − Y)；輸出 Y 會回來改變自己的驅動量。

第二步：把右邊的 Y 移回左邊。

把括號展開，再把含 Y 的項目放在一起：

(1+CG)Y=CGR(1+C G)Y = C G R
公式文字版

Y = CGR − CGY，因此 Y + CGY = CGR，也就是 (1 + CG)Y = CGR。

第三步：求輸出相對於命令的比例。

命令到輸出的傳遞記成 T；在這個單位負回授架構中，它也稱為互補靈敏度函數（complementary sensitivity function）。

T=YR=CG1+CG=L1+LT = \frac{Y}{R} = \frac{C G}{1+C G} = \frac{L}{1+L}
公式文字版

T = Y/R = CG/(1 + CG) = L/(1 + L)；本章沒有額外命令前置濾波器。

分母的 1 + L，是把「輸出回來改變誤差」這件事算進去。在每個頻率，L 是複數；不能只拿幅值套進 |L|/(1 + |L|)，也不能直接把 dB 數字代進去。

先用不旋轉的數字理解回授

先看定值命令的穩態，不急著加入正弦相位。假設 Plant 的定值增益為 100 (mm/s)/A_peak，比例控制器為 C = 0.1 A_peak/(mm/s)，所以 L = 10。

  1. 指定速度 r = 10 mm/s，閉迴路比例為 T = 10 / 11 ≈ 0.9091。
  2. 平台最後為 y ≈ 9.09 mm/s，留下 e = 10 − 9.09 ≈ 0.91 mm/s。
  3. 控制器由這個誤差產生 u ≈ 0.091 A_peak；Plant 再把它變成約 9.09 mm/s，前後就對上了。

這裡只用比例控制，所以必須留一點誤差，才能持續提供對抗阻力的電流；加入積分後的定值跟隨是另一個問題。這個定值算例不是畫在 log 軸的 0 Hz 頻點，只是先用實數把回授關係想通。

三個 0 dB，不能用同一句話解釋

  • Plant 的 0 dB：幅值等於圖上選定的物理單位基準，例如 1 (mm/s)/A_peak。輸入、輸出不是同一種量，不能說「速度等於電流」。

  • 命令到輸出的閉迴路 0 dB：輸出與命令的同頻振幅相同。但若相位落後，仍有跟隨誤差；也不能只憑一個頻點判定整個系統穩定。

開迴路交越頻率與閉迴路頻寬也不是同一個定義。某些設計中兩者數值接近，但不是一看到開迴路過 0 dB，就能把那個數值直接當成所有情況的閉迴路頻寬。

速度迴路與位置迴路，又是另一層關係

像一個小幫手專門顧速度，外面另一個小幫手只管「離目標位置還差多少」。位置控制器把位置誤差換成速度命令，交給裡面的速度迴路去執行。

用專業術語說，這是串級控制（cascade control）。從外層位置控制器看進去，受控對象包含「已閉合的速度迴路」，還要把速度累積成位置；在線性理想關係下，這個累積以 1/s 表示，不是在說又多放了一個位置控制器的積分項。

因此談「開迴路」時，一定還要補上哪一個迴路。速度開迴路、位置開迴路的訊號與方塊不同；不能直接把速度開迴路曲線當成位置開迴路曲線。本章先建立邊界，外層設計與頻寬比例留到後續章節。

想好了，再看答案

在同一個線性小訊號模型與相同工作條件下，只改速度控制器，Plant G 不變；開迴路 L = CG 與閉迴路 T = L/(1 + L) 會改變。電流到速度的 TXT 描述 Plant，不是速度命令到速度回授的閉迴路 T。實機若因調增益改變工作點、飽和或辨識品質，重新量到的 Plant 也可能不同，要另查原因。

BODE LEARNING NOTES / 04

交越頻率、頻寬、PM、GM

分清楚跟得多快，以及離危險還有多遠。

先分開兩個問題：跟得多快，離危險多遠？

想像你在幫推車修正速度。你動作快，推車不一定就跟得快：如果你看到的是稍早的速度，等你加力時，推車可能已經開始變快；原本想修正的動作，反而把它推得更過頭。

用 Bode 調機，也是在同時看兩件事：

  • 響應速度：命令變化得更快時，輸出還跟得上多少？這連到閉迴路頻寬。
  • 穩定裕度：控制的一圈傳遞，離「回來的修正剛好變成助長變化」還有多少餘地？這連到 PM、GM。

本章沿用第三章的單位負回授架構，L 為開迴路傳遞，T = L/(1 + L) 為命令到輸出的閉迴路傳遞。這兩種曲線都無因次，但要讀的點不同；不是先找出某條曲線的 0 dB，再把所有名詞套上去。

交越頻率：先說清楚交越哪一條線

增益交越頻率（gain crossover frequency）記成 f_gc：開迴路 L 的幅值通過 0 dB，也就是 |L| = 1 的頻率。

|L(j2πfgc)|=1|L(j2\pi f_{gc})| = 1
公式文字版

在增益交越頻率 f_gc，開迴路 L 的幅值等於 1，也就是 0 dB。

低頻通常有較大的迴路增益，控制器能積極修正誤差；頻率提高後，迴路增益常逐漸變小。f_gc 可以幫我們觀察這個轉變的位置，但不是一道「過了就完全不修正」的開關。

另一個是相位交越頻率（phase crossover frequency），本章記成 f_pc：L 的相位通過 −180°，或相差整圈的等效角度，例如 +180°、−540°。它不要求同時為 0 dB。

  • f_gc：先看幅值圖的 0 dB，再去相位圖讀 PM。
  • f_pc：先看相位圖的 −180° 等效方向，再去幅值圖讀 GM。

本章用 f 表示 Hz；若工具輸出的是角頻率 ω，需先以 f = ω/(2π) 換算。不同軟體的交越變數名稱可能不同，應核對定義，不能只靠縮寫猜。

頻寬：閉迴路跟隨能力下降到哪裡？

先想像緩慢地改速度命令，輸出能跟到某個比例；再把命令改得越來越快。當輸出的同頻振幅降到低頻比例的約七成，便常把這個位置當作閉迴路的頻寬邊界。

對本章這種穩定、低通型的命令跟隨系統，閉迴路頻寬（closed-loop bandwidth）記成 f_bw，採用相對定值增益 T(0) 下降 3 dB 的第一個向下通過點。

20log10|T(j2πfbw)||T(0)|=-320\log_{10}\frac{|T(j2\pi f_{bw})|}{|T(0)|} = -3
公式文字版

在閉迴路頻寬 f_bw，|T(f_bw)| / |T(0)| = 10^(−3/20) ≈ 0.7079，即相對定值增益下降 3 dB。

這裡是振幅比例，不是「相位落後 3 度」，也不是頻寬以上的速度完全消失。常說的「半功率點」精確對應振幅 1/√2 ≈ 0.7071、−3.0103 dB；本章互動採整數 −3 dB，兩者十分接近，但計算時不混用。

先找低頻基準，再往下找 3 dB。 若 T(0) = 0.5，其基準本來就在約 −6.02 dB；頻寬點應在約 −9.02 dB，不是絕對的 −3 dB。若量測沒有足夠低頻的平坦區，不能任意把第一筆當成可靠的定值增益。

f_gc 與 f_bw 常有關聯，但定義不同，也不保證相等。相位、閉迴路峰值、命令前置濾波與控制架構，都可能改變兩者的關係；對帶通型、非典型或已不穩定的系統，也不能直接沿用這個跟隨頻寬說法。頻寬定義的參考資料。

為什麼 −180° 與 0 dB 放在一起特別重要？

沿控制路徑走一圈，如果變化回來時方向一樣，相減點會把它減掉；但若一圈的相位落後半個週期，回來的變化方向就相反，相減這個反向變化，等於又把原來的變化加大。

用簡單數字想：原本想減掉 +1，結果回來的是 −1；「減掉 −1」就變成「加上 1」。方向之外還要看大小：如果一圈恰好也是一倍，便碰到 L = −1 這個臨界點。

L=-1=1∠(-180circ),1+L=0L=-1=1\angle(-180^\circ),\qquad 1+L=0
公式文字版

L = −1 代表幅值 1（0 dB）、相位 −180°；此時閉迴路分母 1 + L = 0。

這正是第三章分母的意義。若 L 靠近 −1，|1 + L| 很小，閉迴路可能出現很大的峰值。不是任何 −180° 都會失控，也不是任何 0 dB 都叫共振；要一起看幅值、相位與整個回授系統。

PM：在一倍的位置，還能多落後多少角度？

相位裕度（phase margin，PM）先找到開迴路的 f_gc，再讀那個頻率的相位。對常見從低頻向下落後、以 −180° 為相鄰臨界方向的分支：

PM=180circ+∠L(j2πfgc)PM = 180^\circ + \angle L(j2\pi f_{gc})
公式文字版

在開迴路 0 dB 交越處，PM = 180° + 該處的連續分支相位；例如 −120° 對應 PM = 60°。

像是走到一道彎道時，量自己距離危險方向還差多少角度：

  • 在 0 dB 處相位為 −120°，距離 −180° 還有 60°，所以 PM 是 60°。
  • 在 0 dB 處相位為 −170°，只剩 10°，額外的相位落後就更容易碰到臨界方向。
  • 若這個分支的交越相位已到 −190°，對應的 PM 是 −10°，不是還有正的 10° 餘地；但複雜系統不能只靠這個符號做完整穩定判決。

第二章的相位包覆在這裡很重要。−190° 若顯示成 +170°，不能直接算成 180 + 170 = 350° 的 PM；要先還原適合分析的相位分支，或採用能正確處理等效角度的裕度計算法。裕度定義的參考資料。

GM：在反向的位置，還能把增益加大多少？

增益裕度（gain margin，GM）換一個方向讀：先找到 f_pc，再看那個頻率的開迴路幅值，還差多少才到一倍。

GMratio=1|L(j2πfpc)|,GMdB=-20log10|L(j2πfpc)|GM_{ratio} = \frac{1}{|L(j2\pi f_{pc})|},\qquad GM_{dB} = -20\log_{10}|L(j2\pi f_{pc})|
公式文字版

在 −180° 等效相位交越處，GM 倍率 = 1/|L|；GM 的 dB 值 = −該處的開迴路幅值 dB。

例如相位為 −180° 時，開迴路只有 0.5 倍，也就是 −6.02 dB：若把整個迴路增益乘 2，這個點就會變成一倍。因此 GM 是 2 倍，或 +6.02 dB。

GM 的 2 倍，不是再加 2 倍變成 3 倍，而是把目前增益乘 2。 這個「只改增益」的想像也有前提：其餘動態與相位先保持不變。實機若同時改 LPF、Notch 或工作條件，就要重新計算。

一次算完：同一條曲線的四個讀值

為了讓算例能直接對照互動圖，本章使用另一個虛構模型：一個積分環節加上兩個相同的一階低通環節，低通轉折頻率都是 10 Hz；只調整無因次增益 k。不是第三章的馬達參數，也不是你的機台辨識結果。

在預設 k = 0.625 時：

第一步：從幅值找 f_gc，再讀 PM。

在 5 Hz，開迴路幅值恰為 1；相位是 −90° − 2 × arctan(0.5) ≈ −143.13°。所以 f_gc = 5 Hz，PM = 180 − 143.13 ≈ 36.87°。

第二步：從相位找 f_pc，再讀 GM。

在 10 Hz，相位是 −90° − 45° − 45° = −180°；開迴路幅值是 0.625/2 = 0.3125，約 −10.10 dB。所以 f_pc = 10 Hz，GM = 1/0.3125 = 3.2 倍，也就是 +10.10 dB。

第三步：另看閉迴路，找相對基準下降 3 dB 的點。

本模型的 T(0) = 1，所以這次可以直接在閉迴路幅值圖找 −3 dB，得到 f_bw ≈ 8.60 Hz。這個頻率由 T = L/(1 + L) 的複數計算得到，不是把前面的 5 Hz 換個名稱。下面同時標出兩個不同位置。

如果又過一次 0 dB，該看哪一個？

想像道路先下坡、經過一個山丘，再往下走；同一個高度可能經過不只一次。開迴路曲線也可能因共振峰、控制器或濾波器的形狀，再次穿越 0 dB。

第一個向下交越常被用作主要交越頻率，但後面的交越不能忽略：每個增益交越都有對應的相位與 PM，每個相位交越也有對應的幅值與 GM。後面某個交越可能更接近危險條件；只顯示第一個漂亮的 PM，會漏掉它。

另外要分清楚三件事：

  • 共振特徵：相對周圍趨勢凸起的峰，通常要再結合相位與模型／量測判讀；不以是否高於 0 dB 定義。
  • 再交越：曲線又穿過 0 dB。共振可能造成它，但不能反過來把每次交越都叫共振。
  • 穩定風險：與 L = −1、各個交越與整體迴路有關。不是要求峰頂剛好在 −180° 才算共振。

對實機而言，「未找到」最好連同量測範圍一起保留。不要用一個好看的數字掩蓋不知道的部分。

調機時怎麼一起用？

先確認看的確實是該迴路的 L，再查各個交越與裕度；跟隨能力另看 T 的頻寬、峰值與相位。命令前置濾波可以改變跟隨曲線，但不一定改變內部迴路的穩定裕度。

設定最低 PM = 35° 或最低 GM = 6 dB，是在提出工程設計約束，不是自然界規定的門檻。符合門檻也不等於已經最優；還要比較頻寬、峰值、雜訊放大、電流／飽和與實機變異。PM、GM 是分別改相位或增益時的傳統裕度，不是所有增益與相位同時變動的保證，也不能唯一決定超越量或振動程度。

試著用自己的話說一次

某個速度開迴路的第一次交越在 50 Hz，相位為 −140°；後面又在 400 Hz 交越，相位為 −175°。你能只用第一次的 40° PM，說這個迴路很有餘裕嗎？這兩個頻率又能直接當成閉迴路頻寬嗎？

想好了，再看答案

不能只看第一次。按題目的相位分支，兩次交越的 PM 分別是 40° 與 5°；後者更接近 −180°，必須把其他交越、整體穩定性與量測品質一起檢查。它們都是開迴路增益交越頻率，不是閉迴路頻寬；頻寬應另外從穩定閉迴路 T 的低頻基準與下降 3 dB 的點取得。

主互動的解析模型

為了清楚展示有限 GM 與高增益失穩，這一章換用無因次的教學迴路；q = s/(2π × 10) 是正規化複數頻率，不是另一個控制器。回授為 H = 1，沒有命令前置濾波，k > 0。

q=s2π×10,L(s)=kq(1+q)2,T(s)=kq3+2q2+q+kq=\frac{s}{2\pi\times10},\qquad L(s)=\frac{k}{q(1+q)^2},\qquad T(s)=\frac{k}{q^3+2q^2+q+k}
公式文字版

q = s/(2π × 10)，L = k/[q(1 + q)^2]；T = L/(1 + L) = k/(q^3 + 2q^2 + q + k)。

在 s = j2πf 時，令 x = f/10；積分環節提供 −90°，兩個低通環節各提供 −arctan(x)：

|L|=kx(1+x2),∠L=-90circ-2arctan(x)|L|=\frac{k}{x(1+x^2)},\qquad \angle L=-90^\circ-2\arctan(x)
公式文字版

x = f/10；|L| = k/[x(1 + x^2)]，連續相位 = −90° − 2 arctan(x)，角度以度數表示。

因此 f_pc = 10 Hz、GM_ratio = 2/k，增益交越由 x(1 + x²) = k 求得。特徵多項式為 q³ + 2q² + q + k；Routh–Hurwitz 穩定判據是一種利用多項式係數，檢查極點是否全部位於左半平面的方法，不必逐一解出每個根。簡單說，就是另外確認系統自身的變化會逐漸消退，而不只是看圖上的裕度數字。

對這個三次式，條件要求所有係數為正，且 2 × 1 > k，所以穩定範圍是 0 < k < 2。在 k = 2，多項式為 (q + 2)(q² + 1)，有一對純虛根，屬臨界狀態而非漸近穩定。

T(0) = 1 是此積分型迴路的極限值，不是在 log 軸上畫 0 Hz。若 k ≥ 2，互動停止顯示閉迴路跟隨曲線／頻寬，以免把不穩定系統的代數頻率值誤當成可達穩態。

多交越模型與搜尋限制

共振例以另一個開迴路形狀示範，不是把主互動的增益偷偷改掉；固定 k = 0.625，同樣使用 q = s/(2π × 10)。

Lr(s)=0.625q(1+q/8)16q2+0.24q+16L_r(s)=\frac{0.625}{q(1+q/8)}\frac{16}{q^2+0.24q+16}
公式文字版

Lr = 0.625/[q(1 + q/8)] × 16/(q² + 0.24q + 16)；第二個因子為自然頻率 40 Hz、阻尼比 0.03 的二階模態。

其閉迴路特徵多項式為 q⁴ + 8.24q³ + 17.92q² + 128q + 128k，由 Routh–Hurwitz 得到穩定上界 k ≈ 0.2895655。這個固定 k = 0.625 的多交越例已不穩定；互動只顯示開迴路與交越清單，不提供它的有效跟隨頻寬。這是針對此模型的獨立驗證，不是把「有三次交越」當成通用失穩定義。

程式在指定 log 頻段取樣以括住過線區間，再用幾何中點二分法細化；主例相位單調落在 −90°～−270°，共振例落在 −90°～−360°，因此只需檢查其中的 −180° 相位交越。PM 使用這兩個模型的連續相位分支。這不是可直接處理任意 TXT 的通用裕度演算法：稀疏量測、窄峰、剛好碰線未穿越、雜訊與多圈相位都需另行處理。

所有圖的橫軸為 Hz 的 log 軸。跨越點來自模型求根，不是拿畫面上最近的像素或頻點代替。相位圖使用連續分支，避免包覆造成視覺誤判。

裕度不是完整的穩定證明

L = −1 是單位負回授特徵式的臨界點。Nyquist 判據（Nyquist criterion）會結合迴路頻率軌跡對此點的繞行與開迴路右半平面極點，判斷閉迴路右半平面極點數。若有原點極點，輪廓也需適當繞開；不應只看一個 PM 的正負。

傳統 GM、PM 分別考察純增益倍率與純相位變化，不保證兩者同時變化時的全部安全區域。延遲、未建模高頻模態、非線性摩擦、飽和、量測品質與多軸耦合仍可能限制實機性能。這一章只建立讀圖與判斷邊界，不提供實機最佳增益或濾波器建議。

從曲線判斷機械與調參方向

把曲線線索接到物理原因，再選擇值得驗證的調整。

先分清楚：是機械變了，還是迴路變了？

想像用手推一台推車：車上加了重物、輪子比較難轉、車架會彈，各自會讓推起來的感覺不同。但如果你改成用更大的力去修正誤差，也會改變它的動作。機械本身的特性，和控制器怎麼推它，是兩件事。

讀圖前先對齊三件事，才不會對著錯的曲線找原因：

  • 量的是哪一段？ Plant G 是指定輸入到輸出的受控體；開迴路 L 包含控制器與迴路內濾波器；閉迴路 T 是命令到回授的跟隨結果。閉迴路的峰，不一定就是機械 Plant 的共振。
  • 訊號與單位相同嗎？ 速度／電流刻度、速度／安培、速度／力 的 dB 基準不同。整條幅值上下平移，也可能只是單位換了，不是質量變了。
  • 測試條件相同嗎？ 平台位置、負載、激振振幅、運動方向、原有濾波器與回授位置，都可能改變看到的頻率響應。

接下來把「看到的現象 → 可能原因 → 怎麼再確認 → 調參方向」接起來。它是診斷線索，不是看到一個形狀就能唯一認出故障的對照表。

質量與阻尼：更重，和更難推，曲線不一樣

先只看一個不會彎曲的剛體。對直線平台，馬達力要用來加速質量，也要克服隨速度增加的阻力：

F=Mdvdt+Bv,V(s)F(s)=1Ms+BF=M\frac{dv}{dt}+Bv,\qquad \frac{V(s)}{F(s)}=\frac{1}{Ms+B}
公式文字版

F = M × dv/dt + B × v；速度／力 = 1/(M × s + B)。M 的單位是 kg，B 是 N·s/m，這裡的速度是 m/s。

  • 質量／轉動慣量（mass / moment of inertia）：改變速度越快，就越需要力。旋轉系統把 M、v、F 換成 J、ω、τ，對應 J 的單位為 kg·m²、角速度為 rad/s、轉矩為 N·m。
  • 黏滯阻尼（viscous damping）：速度越大，阻力越大，模型中的阻力是 Bv。很慢時，力可能主要花在克服這項阻力，而不是加速。

當慣性項遠大於阻尼項，速度／力接近積分器：頻率增加十倍，幅值約剩十分之一，也就是 −20 dB/dec；速度相對於力約落後 90°。在相同單位與馬達常數下，質量加倍，這段幅值會降低約 6.02 dB。

當阻尼項占優勢，低頻幅值則接近常數、相位接近 0°。因此，「低頻沒有 −20 dB/dec」不等於資料一定錯，也不等於質量真的變得非常大。

第一步：先把電流與速度換到一致的單位

第三步：回到實機，不能只往高頻追 −20 dB/dec

乾摩擦／庫侖摩擦（Coulomb friction）、靜摩擦與黏滑（stiction / stick-slip），不是固定 Bv。小訊號可能推不動、往返過程可能滑動與黏住交替，頻率響應也可能隨激振振幅改變；上面的線性模型不會產生低頻正斜率，不能拿它直接解釋所有摩擦現象。

遇到不規則的低頻，先在允許的行程與電流範圍內，比較不同激振振幅、位置與方向的重複量測。若曲線明顯依振幅改變，就不能只當成一個固定 LTI Plant。可信程度應來自重複性、相位、斜率、量測品質與模型殘差，不是任意給一個看似精準的百分比。

即使更高頻出現漂亮的 −20 dB/dec，也可能只是局部機構的等效慣性，不代表整台平台的總質量。下一個雙質量例子就是原因。

共振與反共振：不是跨過 0 dB 才叫共振

想像兩台小車用彈簧連在一起，你只推前面那台。慢慢推時，兩台大致一起動；推得比較快，彈簧會壓縮、拉長，兩台就可能不同步。在某些快慢下，彈簧儲存與釋放能量，讓振動特別容易被激起。

  • 共振（resonance）：某個模態在激振頻帶附近出現較大的動態反應，常表現為相對鄰近趨勢凸起的峰，並伴隨相位變化。峰值是否高於 0 dB 取決於曲線與單位，不是共振定義。
  • 反共振（antiresonance）：某一輸入／輸出關係的反應被不同動態路徑抵消，形成谷。谷是「這個量測輸出比較小」，不是「所有地方都不動」。
  • 模態（mode）與阻尼比（damping ratio）：模態是系統的一種振動形態；阻尼比 ζ 描述這種振動衰退的程度。輕阻尼通常讓峰更尖，但實測峰頂不一定正好等於無阻尼自然頻率。

增益、PI、低通與延遲：每種變化都有不同指紋

先問「想改善哪個頻段」，再選工具。不要把所有反應變慢都當成增益不夠，也不要看到高頻尖峰就一路降低低通截止頻率。

  • 比例增益 Kp：固定其他項目時，開迴路幅值整體上移，相位不變；但交越移到另一個頻率，讀到的相位可能更差。提高 Kp 不會把機械 Plant 的共振消除。
  • PI 控制器：積分加強低頻誤差修正，但會在相關頻段增加相位落後。固定 Kp，積分時間 Ti 越小，積分越強；不能把「時間變小」誤讀成「作用變弱」。
  • 低通濾波器（LPF）：降低高頻增益，也增加相位落後。適合處理較廣的高頻內容，但截止頻率過低，可能先吃掉交越附近的裕度。
  • 純延遲（pure delay）：訊號晚一段固定時間才到，幅值不變；頻率越高，這段等待占的週期比例越大，相位落後越多。

Notch：把特定頻帶壓低，不是越深越好

想像把容易晃動的那一段節奏「少用力推一些」。陷波濾波器（notch filter）在中心附近降低訊號幅值，讓迴路較不容易激起該頻帶；它沒有把彈簧變硬，也沒有保證負載在任何外力下都不振。

本章使用以下三個參數。不同驅動器可能採用不同公式，先確認定義再對應：

  • f_n：陷波中心頻率。
  • Q：此公式的寬度參數；固定其他條件時，越大越窄。中心不準或共振漂移時，太窄可能漏掉峰。
  • D：中心剩餘幅值比例。D = 0.1 剩 10%，為 −20 dB；D = 0.5 剩 50%，約 −6.02 dB。越小越深，不是越大越深。

某平台的低頻曲線會隨激振振幅改變；不同位置在 400、430、460 Hz 各出現一個尖峰。有人建議：「往高頻找到 −20 dB/dec 就當總質量，再用最深的 430 Hz 窄 Notch。」你會先質疑哪兩件事？

想好了，再看答案

這張 Bode 值得相信嗎

從原始波形到頻率響應，分清楚量得出來與量得可信。

曲線畫得出來，不代表每個點都量得好

想像你在房間裡拍手，再用錄音機量回音。錄到的聲音除了回音，還可能有冷氣、談話與錄音機本身的雜訊。電腦可以把它們全部畫成曲線，但「畫得出來」與「這個點代表房間的回應」是兩件事。

馬達量測也一樣。我們要先問：

  • 量的是誰對誰？ 注入位置、輸入／輸出訊號與單位是否正確？
  • 量的時候穩定了嗎？ 切頻暫態、飽和、摩擦與位置變化是否混進資料？
  • 重複量測的關係一致嗎？ 這是平均與相干性（coherence）主要幫忙觀察的事。

本章接回「電流命令 → 速度回授」：u(t) 是注入後的總電流命令，不是只有額外注入的正弦；y(t) 是速度回授。每個頻率、每個新區段得到一組複數 U_k、Y_k，k 是第幾次量測，不是第幾個頻率。

以下功率與相干性算例使用 U：A_peak、Y：mm/s。若來源是電流刻度，先按第二章的單位契約換算；若量到的是命令而不是實際電流，頻率響應也包含命令到電流的動態，不能自動當成純機械。

FFT 與同步解調：都在問波形裡有多少指定的節奏

先不要想 Bode。韌體最先拿到的是一串隨時間變化的數字。要知道其中的 100 Hz 成分，可以準備兩個 100 Hz 參考節奏：一個餘弦、一個正弦，分別和每個取樣值相乘，再累加。

節奏相同的成分，在相乘後會留下穩定的部分；節奏不同的成分，常會正負抵消。專業上稱為同步解調（synchronous demodulation）或相敏檢波（phase-sensitive detection）。用兩個相差 90° 的參考，可以同時取得同相／正交分量（in-phase／quadrature components，I/Q），也就是複數的實部與虛部。

本章採 x(t) = A cos(2πft + φ) 對應 X = A exp(jφ) 的峰值相量慣例。對一段 N 點資料，加權投影可寫成：

X(f)=2∑n=0N-1wn∑n=0N-1wnxn[cos(2πfnFs)-jsin(2πfnFs)]X(f)=\frac{2}{\sum_{n=0}^{N-1}w_n}\sum_{n=0}^{N-1}w_n x_n\left[\cos\left(\frac{2\pi fn}{F_s}\right)-j\sin\left(\frac{2\pi fn}{F_s}\right)\right]
公式文字版

X(f) = 2/sum(w) × sum{w[n] x[n] [cos(2πfn/Fs) − j sin(2πfn/Fs)]}。實部累加 x×cos，虛部累加 −x×sin；w 為窗函數，Fs 為取樣頻率。此峰值倍率不適用於 DC 與 Nyquist 頻點。

這個式子不是對任意短資料都保證得到「真正振幅」。它需要足夠的量測長度、合適的窗與穩態條件，避免其他成分、負頻影像或暫態污染結果；本章互動刻意選擇容易對照的理想單頻情境。

離散傅立葉轉換（discrete Fourier transform，DFT）是在一整排離散頻率上做類似的投影；快速傅立葉轉換（fast Fourier transform，FFT）是更快算出 DFT 的演算法，不是另一種物理量。

  • FFT：像把錄音裡不同節奏逐一列出來，得到一排複數頻格（frequency bins）。
  • 同步解調：已知道自己注入 100 Hz，就集中取得這個頻率的複數；不必先算完整頻譜。

兩者都可以產生 Bode 所需的幅值與相位。差別在頻率格點、窗、累加／低通方式、時序與正規化，不能只看名稱就認定結果完全相同。

取樣長度、頻格與洩漏，為什麼會影響量測？

10.5 Hz 在一秒內走了 10.5 個週期，不在 1 Hz 格點上。有限長度資料被當成重複片段時，接縫可能不連續，能量就散到附近頻格，稱為頻譜洩漏（spectral leakage）。這不表示機械突然有很多共振。

  • 延長資料：可縮小頻格間距，通常也改善分辨相近成分的能力，但機台必須在這段時間內維持相同條件。
  • 加窗（windowing）：例如 Hann 窗可降低遠處旁瓣，但主瓣會變寬；不是沒有代價。本圖以窗的總權重校正峰值振幅，沒有使用 PSD 正規化。
  • 補零（zero padding）：讓頻譜取點更密，不等於取得更長的實際資料，也不會憑空分開原本分不清的兩個頻率。

另外，取樣前／降採樣前的抗混疊（anti-aliasing）不能省略。超過可辨頻帶的成分若已混疊進來，FFT 或同步解調都不能事後替你辨認真實來源。

「一段內累加」與「多段平均」不是同一件事

同步解調本身就會把一段時間內的取樣累加，取出一組 U_k、Y_k。接下來要算 coherence，還需要同一頻率的多組新資料。

可以把它想成：第一次拍手，用一段錄音取出回音；再拍手、再錄一段，看看相同輸入與輸出的關係是否重現。不是把第一次錄音複製八份。

層次做什麼得到什麼

所以，不一定要韌體計算 coherence。若 UI 收到每次的實部／虛部，就能累加；若韌體只送出每頻率一組最終 U/Y，UI 便無法還原跨段的一致性。另一條路是由韌體送出已累加的功率、互功率與有效段數。

Coherence 在問什麼？gamma 又是什麼？

假設每次拍手的音量、起始時刻略有不同，但回音始終是相同的放大與延後。扣掉每次拍手本身的變化後，回音關係仍很一致。若談話聲混進來，某些輸出就不能只用這個固定關係解釋。

專業上，本章的 coherence 指幅值平方相干性（magnitude-squared coherence），記為 γ²，讀作「gamma 平方」。它比較同一頻率的多組資料，觀察輸入與輸出的固定線性關係能有多一致。γ 本身是其非負平方根；軟體若只寫 gamma，仍需確認採哪個定義。

數值範圍是 0～1，但不是「這張 Bode 有幾成正確」的機率，也不是穩定裕度。要理解這個數字，先看它用哪些量算出來。

功率為什麼用平方？這裡不是在算瓦特嗎？

如果直接平均正弦波，正半週與負半週會抵消成零，但它明明還在振動。要描述訊號「有多強」，就把正負方向去掉，同時讓大幅度有更大的權重。均方值（mean square）就是常用的強度量。

對複數 U = a + jb，把它想成平面上的一支箭頭：水平長 a、垂直長 b。依畢氏定理，箭頭長度的平方是 a² + b²，不是直接把 U 平方：

|U|2=a2+b2=conj(U)U,mean(u2)=A22當 u(t)=Acos(2πft+φ)|U|^2=a^2+b^2=\mathrm{conj}(U)U,\qquad \mathrm{mean}(u^2)=\frac{A^2}{2}\quad\text{當 }u(t)=A\cos(2\pi ft+\phi)
公式文字版

U = a + jb 時，|U|² = a² + b² = conj(U)×U；峰值振幅為 A 的正弦，在完整週期上的時間均方值是 A²/2。

兩個平方差一個 1/2，是因為本章用峰值相量。若使用 RMS 相量，該相量的平方就直接等於正弦均方值。計算時必須知道慣例，不要混用；兩通道一致的共同倍率，在後面的比值中會約掉。

在訊號處理裡，自功率（auto-power）表示訊號自己的平方強度。這裡 Puu 的單位是 A_peak²，Pyy 是 (mm/s)²，並不自動是電功率 W。寬頻的功率頻譜密度（power spectral density，PSD）還有「每 Hz」與窗／取樣率的正規化，不能直接和本章單頻相量強度混成同一個數字。

共軛的本質：鏡射方向，再扣掉輸入相位

複數共軛（complex conjugate）只把虛部變號：a + jb → a − jb。幾何上是把箭頭對實軸鏡射，長度不變、角度變成相反數；它不是把整個複數取負。

例如 U = 1 + j2，共軛是 1 − j2，不是 −1 − j2。若 Y = 3 + j4，乘開來是：

conj(U)Y=(a-jb)(c+jd)=(ac+bd)+j(ad-bc)\mathrm{conj}(U)Y=(a-jb)(c+jd)=(ac+bd)+j(ad-bc)
公式文字版

U=a+jb、Y=c+jd；conj(U)×Y 的實部 = ac+bd，虛部 = ad−bc。例如 (1−j2)(3+j4)=11−j2，使用 j²=−1。

複數相乘時，長度相乘、角度相加。共軛把 U 的角度改成 −φu，所以乘上 Y 後，角度就是 φy − φu：留下輸出相對輸入的相位差，而不是兩個絕對相位相加。

更直接地說：若每次的輸出都滿足 Y_k = G U_k，則：

conj(Uk)Yk=G|Uk|2\mathrm{conj}(U_k)Y_k=G|U_k|^2
公式文字版

若 Yk=G×Uk，則 conj(Uk)×Yk = G×|Uk|²。每次輸入的相位消掉，只剩共同的系統關係 G，乘上該次輸入強度。

這就是互功率（cross-power）有用的原因。它不是抽象地「做一次乘法」：它先讓各次資料用自己的輸入當相位基準，再把這些關係放在一起比較。

平均什麼，才能同時得到 Bode 與 coherence？

同一頻率量到 M 組新的 U_k、Y_k，先計算三項平均：

Puu=1M∑k=1M|Uk|2,Pyy=1M∑k=1M|Yk|2,Puy=1M∑k=1Mconj(Uk)YkP_{uu}=\frac{1}{M}\sum_{k=1}^{M}|U_k|^2,\qquad P_{yy}=\frac{1}{M}\sum_{k=1}^{M}|Y_k|^2,\qquad P_{uy}=\frac{1}{M}\sum_{k=1}^{M}\mathrm{conj}(U_k)Y_k
公式文字版

Puu = mean(|Uk|²)；Pyy = mean(|Yk|²)；Puy = mean(conj(Uk)×Yk)。本章固定 Puy 的共軛放在輸入 U；不同文件的下標命名可能相反，應看實際乘法。

由同一批資料得到 H₁ 頻率響應估測器（H₁ frequency-response estimator）與 coherence：

H1=PuyPuu,γ2=|Puy|2PuuPyyH_1=\frac{P_{uy}}{P_{uu}},\qquad \gamma^2=\frac{|P_{uy}|^2}{P_{uu}P_{yy}}
公式文字版

H1=Puy/Puu；coherence=γ²=|Puy|²/(Puu×Pyy)。Bode 幅值取 20log10|H1|，相位取 atan2(Im(H1),Re(H1))；有物理單位時仍需指定 dB 基準。

白話來說：Puu 記錄「平均推了多少」，Pyy 記錄「平均回應了多少」，Puy 記錄「以每次輸入為基準後，留下多少一致的關係」。coherence 把它們組合成沒有單位的比例。

在 Y = G U + N、且輸出雜訊 N 與輸入不相關的模型下，平均能讓互功率中的隨機雜訊項趨近抵消；但雜訊的平方強度仍留在 Pyy。因此 H₁ 有機會更接近 G，coherence 則反映可由這個線性關係解釋的強度比例。這些條件不成立時，不能沿用同樣解讀。

若各次輸入強度不同，H₁ 等同於以 |U_k|² 加權的 Y_k/U_k 平均，通常不等於每次比值的算術平均。本例各次 |U|² = 1，兩者才恰好相同。

為什麼只量一次，coherence 一定是 1？

當只有一組非零 U、Y，分子 |conj(U)Y|² 就是 |U|²|Y|²，和分母完全相同，因此結果必為 1。單次資料沒辦法告訴你「下一次是否也有相同關係」。

這也說明：不能先算每組 coherence，再拿來平均；每組都是 1，平均後仍是 1。正確順序是先平均功率／互功率，最後再做比值。如果輸入或輸出的平方和為零，coherence 分母為零，應顯示「無法計算」，不能硬填 0 或 1。

要平均幾次？不是越多就越接近 1

用新的量測區段平均，是為了降低隨機波動、看清固定關係，不是把 coherence 往 1 加分。

  • M = 8 可作為逐點掃頻的起始設定，再用 16 或更多次比較重複量測的差異；它不是普遍適用的合格門檻。
  • 區段越少，估測越容易波動，coherence 也可能偏樂觀；區段重疊、系統記憶或低頻暫態會減少真正獨立的資訊，八段不保證等於八次獨立觀察。
  • 若機台一直在飽和、比例設錯或條件漂移，平均再多也不能修正原因。若輸出訊號本來就很弱，增加平均能讓估測更集中，但母體 coherence 不會因此自動提高。

哪些地方 coherence 可能低？該如何判讀？

想像回音變得很小，但冷氣聲沒有變小；錄音仍有聲音，卻比較難看出拍手與回音的關係。反共振附近常會有類似問題，但不是「反共振必定低 coherence」。

在完全線性、無雜訊且響應不為零的模型裡，即使有反共振谷，coherence 仍可等於 1。若輸出剛好完全為零，公式則未定義，而不是自動等於 1。

還有兩個重要邊界：

  • 高 coherence 不保證穩定或單位正確。 把輸入／輸出乘上固定非零倍率，coherence 不變，但 FRF 增益和慣量換算會改變。PM、GM 與閉迴路穩定，仍要看迴路模型及第四章的條件。
  • 閉迴路中的雜訊可能透過回授改變電流命令。 此時 U 與輸出雜訊不一定獨立，H₁ 可能有偏差；輸入通道本身有雜訊也會破壞簡單的 H₁ 假設。不能只憑高 coherence 宣稱已取得無偏的純機械 Plant。

因此，本章不給一個通用的「大於多少一定可信」門檻。判讀應同時看激振／量測條件、重複性、輸出強度、coherence 與曲線的物理合理性。只含每頻點幅值／相位的最終 TXT，若沒有多段資料或統計量，也不能事後補算真正的 coherence。

附錄 · 第六章的計算、程式與來源

Welch 分段平均，和逐點正弦掃頻有什麼關係？

Welch 方法（Welch's method）把一筆較長的時間資料切成多段，每段加窗、做 DFT，再平均自功率與互功率。為了使用更多資料，區段可以重疊；但重疊段不必然是獨立觀察。

逐點掃頻則是在同一個注入頻率持續取得新區段，再換下一個頻率。它與 Welch 共用「先從多段建立功率／互功率統計，再估測頻率響應與 coherence」的概念，但激振方式、頻譜、頻格與正規化不必相同。不能把「取得八組同步解調值」直接當成已實作完整寬頻 Welch 分析。

為什麼相干性介於 0 與 1？

把同頻率的 M 個輸入複數排成一長串 U = [U₁,…,U_M]，輸出也排成 Y = [Y₁,…,Y_M]。互功率的加總是這兩串資料的複數內積（complex inner product）；兩個自功率加總則是各串的長度平方。

柯西–施瓦茨不等式（Cauchy–Schwarz inequality）說：內積的大小，不會超過兩個長度的乘積。白話是「兩串資料能對齊的共同部分，不可能比它們各自全部的大小還大」：

|∑kconj(Uk)Yk|2≤(∑k|Uk|2)(∑k|Yk|2)\left|\sum_k\mathrm{conj}(U_k)Y_k\right|^2\leq\left(\sum_k|U_k|^2\right)\left(\sum_k|Y_k|^2\right)
公式文字版

|sum(conj(Uk)×Yk)|² ≤ sum(|Uk|²) × sum(|Yk|²)。分母非零時，兩邊相除便得到 0 ≤ γ² ≤ 1。

當所有段的 Y_k 都是同一個複數 G 乘上 U_k，等號成立。只有一段時總能找到 G = Y/U，所以得到 1 是必然結果，沒有跨段檢查能力。

第一性原理的另一個讀法：不能解釋的剩餘有多少？

H₁ 也是使所有段的平方誤差總和最小的複數線性比例：找一個 H，讓 Y_k − H U_k 的長度平方加總最小。對這一批資料，代入 H₁ 後：

∑k|Yk-H1Uk|2=∑k|Yk|2-|∑kconj(Uk)Yk|2∑k|Uk|2=(∑k|Yk|2)(1-γ2)\sum_k|Y_k-H_1U_k|^2=\sum_k|Y_k|^2-\frac{|\sum_k\mathrm{conj}(U_k)Y_k|^2}{\sum_k|U_k|^2}=\left(\sum_k|Y_k|^2\right)(1-\gamma^2)
公式文字版

最佳線性比例 H1 的剩餘平方和 = 輸出平方和 × (1−γ²)。因此 γ² 可讀成這批同頻率資料中，由單一複數比例能解釋的輸出平方強度比例；不是系統正確機率。

在母體模型 Y = G U + N，且 E[conj(U)N] = 0 時，才進一步得到訊噪比的解讀：

γ2=|G|2Puu|G|2Puu+Pnn\gamma^2=\frac{|G|^2P_{uu}}{|G|^2P_{uu}+P_{nn}}
公式文字版

輸出雜訊與輸入不相關時，母體 γ² = 有效輸出強度 / (有效輸出強度 + 雜訊強度)。有限 M 的樣本比值不一定等於這個母體值，也不保證隨 M 單調變化。

UI 累加的簡單 C 範例

以下只示範一個頻率的資料累加；UI 可用自己的語言照同一公式實作。coh_reset 在換頻率時呼叫，等待段不呼叫 coh_add。每完成一個新的、輸入／輸出配對的有效區段，才呼叫一次 coh_add。

#include <math.h>

typedef struct {
    unsigned int count;
    double uu, yy, uy_re, uy_im;
} Coherence;

void coh_reset(Coherence *s) { *s = (Coherence){0}; }

/* U = ur + j*ui, Y = yr + j*yi */
void coh_add(Coherence *s, double ur, double ui,
             double yr, double yi)
{
    s->uu    += ur*ur + ui*ui;
    s->yy    += yr*yr + yi*yi;
    s->uy_re += ur*yr + ui*yi;  /* real(conj(U)*Y) */
    s->uy_im += ur*yi - ui*yr;  /* imag(conj(U)*Y) */
    s->count++;
}

/* 1: 可計算；0: 資料不足或無效。H1 單位 = Y單位/U單位。 */
int coh_result(const Coherence *s, double *h_re, double *h_im,
               double *gamma2)
{
    if (s->count < 2 || !(s->uu > 0) || !(s->yy > 0)) return 0;
    double den = s->uu * s->yy;
    double num = s->uy_re*s->uy_re + s->uy_im*s->uy_im;
    if (!isfinite(den) || !isfinite(num) || !(den > 0)) return 0;
    double g = num / den;
    if (!isfinite(g) || g < 0 || g > 1.0 + 1e-10) return 0;
    *h_re = s->uy_re / s->uu;
    *h_im = s->uy_im / s->uu;
    *gamma2 = g > 1.0 ? 1.0 : g; /* 只修正極小浮點誤差 */
    return isfinite(*h_re) && isfinite(*h_im);
}

直接使用加總，因為共同的 1/M 在 H₁ 與 coherence 比值中會約掉；若要顯示平均自功率，再將 uu、yy、uy 除以 count。先呼叫 coh_reset，依正文四列資料各呼叫一次 coh_add，再呼叫 coh_result，應得到 h_re = 2、h_im = 1、gamma2 ≈ 0.9950248756。

這是公式骨架，不含封包、超時、遺失區段或大型數值的穩健累加。實際程式還應在入口拒絕非有限資料、核對頻率與區段編號、確認兩通道相同窗與正規化，並處理溢位／下溢。不要用強制限制 0～1 掩蓋統計量配錯或公式錯誤；一段與零功率應有明確的「無法判讀／計算」狀態。

四組互動的假設與取樣範圍

  • 第一組用 Fs = 256 Hz、u = cos(2πft) A_peak、y = 0.6 cos(2πft−π/3) mm/s，固定 f = 10 或 10.5 Hz、長度 1 或 2 秒；以直接 DFT 示範 FFT 會計算的頻格，並非另寫 FFT。窗為矩形或週期型 Hann，係數採峰值慣例；頻譜顯示 0～30 Hz。這些指定頻率／段長使目標投影中的負頻影像可抵消，不能推廣為任意短窗的無偏振幅保證。
  • 第二組逐列使用正文四筆手算資料；不是由特定機械模型產生，也沒有用其正相位聲稱馬達特性。
  • 第三組固定單頻 G = |G| exp(−jπ/3)，|G| = 1 或 0.05 (mm/s)/A_peak；每組 |U| = 1 A_peak、相位改變。輸出加入獨立、零均值、等方差的複數高斯雜訊，sqrt(E|N|²) = 0、0.3 或 1 mm/s。可重現的種子產生同一輪 32 組，滑桿只選前 M 組；「換一輪」才改種子。低響應模式只代表輸出弱，不是完整反共振機械模型。複製模式刻意重用第一組，僅用於錯誤示範。
  • 第四組只做時間預算，沿用至少 100 ms 與一週期的段長下限；不是韌體實作或安定判斷器。1、10、100 Hz 配 4、8、16 段，等待與設定段長可分別調整。
