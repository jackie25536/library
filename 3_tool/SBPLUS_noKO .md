## 目前方案：電壓損失修正＋R–L 電流模型

**目標是用同一組參數，讓 P1、P2 的穩態模型電流都接近量測電流。**

目前只做旁路驗證：

- 電流迴路仍使用原始 `iq`。
- 模型輸出為 `iq1`，暫不接入控制。
- `K_o = 0`。
- 假設反電動勢影響可忽略。
- 先驗證正向電流工作區，電壓誤差暫以固定值近似。

這是待驗證的候選方案，不是已確認的 ACS 內部實作。

### 1. 固定模型參數

| 參數 | 用途與設定 |
|---|---|
| `R_model` | 模型電阻，單位 Ω，先使用可信的馬達電阻值 |
| `L_model` | 模型電感，單位 H，先保留原值 |
| `V_bus_model` | 測試期間母線電壓的可信代表值，單位 V |
| `Ts` | 模型更新週期；每次 20 kHz 中斷更新時為 `50e-6 s` |
| `U_loss_pos` | 正向工作區的固定等效電壓修正量，單位 V，由校準取得 |

**之前若為了讓 P1 對齊而調低電壓比例、或調高模型電阻，先恢復可信的基準值，避免重複修正。**

只修改模型的參數副本，不改既有 PI 增益、PWM 或保護設定。

### 2. 在 P1 校準 `U_loss_pos`

保持原始 `iq` 回授，等待 P1 停穩。

先計算理想電壓：

$$
\begin{aligned}
m[k-1]&=2D_{\mathrm{applied}}[k-1]-1\\
u_{\mathrm{ideal}}[k-1]&=V_{\mathrm{bus,model}}m[k-1]
\end{aligned}
$$

`D_applied` 必須對應**已經作用在馬達上的 PWM**；不能直接拿尚未生效的新命令代入。

再取同一段穩態時間的平均值：

$$
U_{\mathrm{loss,pos}}
=
\overline{u_{\mathrm{ideal}}}
-
R_{\mathrm{model}}\overline{iq}
$$

意思是：

> 理想 PWM 換算電壓，扣掉依量測電流推算的電阻壓降，差值先作為固定電壓修正量。

校準時注意：

- **算出後固定使用，不要每拍依 `iq` 重算。**
- 若得到負值，不要取絕對值硬當成正向損失。
- 這是等效修正量，可能包含電壓、電阻或量測誤差；不能直接認定全是 dead time。

沿用先前的教學例子：

$$
U_{\mathrm{loss,pos}}
=
48\times0.01-4\times0.09
=
0.12\ \mathrm{V}
$$

這個 `0.12 V` 只是例子，不能直接套入你的設備。

### 3. 每拍重建電壓，再更新電流

固定運算流程：

**已生效 PWM → 理想電壓 → 扣除等效損失 → R–L 模型 → `iq1`**

重建電壓：

$$
\hat u[k-1]
=
V_{\mathrm{bus,model}}m[k-1]
-
U_{\mathrm{loss,pos}}
$$

前向歐拉更新：

$$
\hat i[k]
=
\hat i[k-1]
+
\frac{T_s}{L_{\mathrm{model}}}
\left(
\hat u[k-1]
-
R_{\mathrm{model}}\hat i[k-1]
\right)
$$

其中 `i_hat` 是模型自己保留的電流狀態，不是每拍重新載入的 `iq`。

**啟動時只初始化一次：**

```c
i_hat = iq_valid;   // 有效量測，單位 A
```

**每拍執行的核心程式：**

```c
// 前提：R_model、L_model、Ts 均為有效正值。
// 此段只更新旁路模型，不改實際 PWM 或電流回授。

float m_prev = 2.0f * D_applied_prev - 1.0f;

float u_ideal_prev = V_bus_model * m_prev;
float u_hat_prev   = u_ideal_prev - U_loss_pos;

float i_next = i_hat
             + (Ts / L_model)
             * (u_hat_prev - R_model * i_hat);

i_hat = i_next;
iq1   = i_hat;
```

P1→P2→P1 的過程中，**不要在每個位置重新初始化模型或重新校準參數**，否則會掩蓋跨工作點的誤差。

### 4. 精確離散版本：只替換電流更新那一行

初始化或參數變更時計算：

$$
a=e^{-R_{\mathrm{model}}T_s/L_{\mathrm{model}}},
\qquad
b=\frac{1-a}{R_{\mathrm{model}}}
$$

每拍更新改為：

```c
float i_next = a * i_hat + b * u_hat_prev;
```

兩種更新方式擇一。

前向歐拉需滿足：

$$
0<
\frac{R_{\mathrm{model}}T_s}{L_{\mathrm{model}}}
<2
$$

這是理想模型的穩定條件，並不保證近似精度。這次調整的重點仍是 `u_hat`，不是更換離散方式。

### 5. 用 P2 驗證，不再重新調參

完成 P1 校準後，固定所有參數，依序觀察：

| 狀態 | 要確認的事情 |
|---|---|
| P1 停穩 | 校準後 `iq1` 與 `iq` 接近 |
| P2 停穩 | 不重新調參，偏差是否也減少 |
| 返回 P1 停穩 | 是否恢復原本的一致結果 |

每次用同一段穩態時間比較平均值，並記錄 `iq`、`iq1`、`u_ideal`、`u_hat`。

- **P1、P2 都改善**：支持這個局部固定電壓修正方案。
- **只有 P1 改善**：固定修正不足，接著檢查比例或電流相關的電壓誤差。
- **模型自己不滿足 `平均 iq1 ≈ 平均 u_hat / R_model`**：先查程式、單位、狀態更新與限幅。

### 6. 這版先不要做的事

- 不把 `U_loss_pos` 加到實際 PWM 命令。
- 不把 `iq1` 接入電流迴路。
- 不加入 `K_o` 掩蓋模型偏差。
- 不把固定減法直接推廣到負電流或跨零工作區。
- 不用模型曲線變平滑，代替位置 jitter 的驗證。

**這一步先驗證「電壓重建能否跨工作點保持一致」。通過後，再處理暫態、正負電流與模型回授切換。**
